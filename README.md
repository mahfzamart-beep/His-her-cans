# Cloud Momos — design preview

This branch contains the Cloud Momos website preview, adapted from the supplied Cloud Momos HTML reference.

## Preview scope
- Original Cloud Momos visual composition and green, cream, and orange palette
- Desktop and mobile layouts
- Ready-to-eat and frozen momo product sections
- Embedded food photography and mascot artwork
- Client-side cart drawer and quantity controls

## Not connected yet
This is a design preview only. It does not submit orders, charge payments, reserve inventory, or persist cart contents. Product prices, pack sizes, delivery rules, and checkout will be connected only after those business details are confirmed.

## Safety
- This work is isolated to the `cloud-momos-preview` branch.
- The `main` branch and previous His & Her Cans source remain preserved.
- The existing Supabase records have not been modified.
- Production aliases and custom domains have not been changed.
