# Cake Can Catcher — His & Her Cans

A standalone front-end prototype for the Cake Can Catcher mini-game.

## Current preview features
- Responsive mobile/desktop play area
- Keyboard arrows, on-screen arrows, and touch/drag controls
- Falling cake items, score, lives, and 30-second rounds
- Mischievous mascot "Can-ny" with playful teasing and win/lose reactions
- Daily challenge and leaderboard preview panels

## Important: prototype only
This repository is intentionally separate from the live His & Her Cans website. This first build is a visual/gameplay prototype. It does **not** yet provide secure accounts, server-enforced five daily chances, shared leaderboard, points ledger, coupon issuance, or checkout redemption. Those require a verified backend integration and database rules. Do not use local browser storage as an authority for rewards.

## Next integration phase
Connect the game to the existing His & Her Cans Supabase project after reviewing its schema and authentication setup. Preserve guest checkout and do not change the live site until its source and integration point are confirmed.
