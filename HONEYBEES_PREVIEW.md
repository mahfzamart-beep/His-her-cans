# Honeybees Preview

This branch is an isolated visual preview of the Honeybees storefront and admin interface.

- Storefront: `index.html`
- Admin preview source: `admin/index.html`
- Product range: Honey Mixed Nuts (50g), Honey Roasted Almonds (50g)
- Provisional test prices: ৳119 and ৳139 respectively

The checkout and admin screen are preview-only. No live orders, payment data or Supabase records are changed by this branch.
